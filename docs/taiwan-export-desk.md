# Partner Network B2B sales kit

13 October 2026. Vietnamese buyer brief at `/export/taiwan`, reused from the initial Taiwan connector request. The owner confirmed that the connector and buyer communicate in Vietnamese, so the page and kit builder have no language selector. There is no home navigation/sitemap addition; noindex supports sharing a sales brief without changing the retail catalog or opening Partner Network registration. Noindex is not private access control.

## Kit builder and PDF

`/admin/partner-network` has a fourth **Bộ chào hàng** tab. A manager can generate a generic brief or select an approved partner from the existing authenticated snapshot. Approved partners have their own kit tab in `/partners/network`; pending/rejected/disabled profiles gain no referral privileges. Select 1–4 teas and VND/TWD/USD/CNY. `lib/export-sales-kit.js` validates the selection and creates a stable share URL. Malformed/repeated selections return 404 instead of silently showing another assortment. The public ledger, calculator and enquiry tea choices all follow the same selection.

Only the full public partner code (`HL-P-` plus 32 UUID hex characters) is carried as bounded `utm_content`. Names, contacts and internal margins never enter the URL. This is a provenance hint for review, not authenticated referral ownership or commission entitlement. A kit is a generated link, not a new persistent assignment record or CRM.

`lib/export-sales-profiles.js` contains the small whitelist of owner-approved public presentation contacts. `/export/taiwan` is the generic edition; `/export/taiwan?profile=anh-long` shows **Anh Long · 078 229 3579 · Đối tác được Hoàng Long ủy quyền** alongside Hoàng Long's existing contact. Unknown/repeated profile parameters return 404. No private partner data is automatically published. Managers select a contact edition separately from an approved referral code; choosing a public presentation contact neither approves an account nor grants commissions. Share links and the full-range link retain the profile. No portrait, extra authority, email or messaging account is invented.

The actual downloads `/downloads/hoang-long-b2b-sales-kit-vi.pdf` (generic) and `/downloads/hoang-long-b2b-sales-kit-anh-long.pdf` (Anh Long) are Vietnamese overviews of **all four teas**, with dated VND prices, confirmed EXW place/packing, real photographs, four simple ordering steps, buyer brief, contacts and a QR to the corresponding web edition. The UI labels their full scope. For a selected assortment/current displayed currency, the web page provides browser **In / lưu PDF**.

Rebuild the generic overview with `python3 scripts/build-b2b-sales-kit.py` and the personalized edition with `--profile anh-long`. The authoring script requires Node, ReportLab, Pillow and four Vietnamese-capable Noto Sans/Serif font files (use `--font-dir` outside the bundled runtime). It reads prices/revision and approved public contacts directly from the repository; no network, credentials or new app dependencies. Re-render and visually review every page of both editions after changing approved facts/prices. Static PDF currency rates are intentionally absent; the QR opens current conversions.

## Pricing

`lib/export-teas.js` is the source for the four reference offers. `GET /api/export-prices` uses a fixed, keyless ExchangeRate-API VND feed with a one-hour server cache and six-second timeout. It returns product conversions only, not a raw exchange-rate feed. Provider attribution and update time are shown. Source data updates daily, not tick-level realtime. Older-than-48-hour foreign estimates are disabled. An unavailable feed retains VND source prices and never uses fabricated fallback rates. The calculator is indicative goods value; a formal quotation specifies currency and EXW place. Existing financial quote/order ledgers remain VND.

## Existing commercial flow

`POST /api/export-enquiries` validates buyer details, then reuses the service-only contact intake handler and existing `submit_event_enquiry` RPC. This retains origin/body/contact validation, IP/contact throttles, honeypot, private records, idempotency and transactional create/link to `trade_opportunities`. No migration or new credentials are required. The shared receipt remains `HL-E-…` and the campaign column remains `event_contact_v1`; actual bounded UTMs and `[Taiwan export / EXW]` details are retained in the saved note in Pipeline's shared contact inbox.

The form is collapsed under **Gửi nhu cầu để Hoàng Long liên hệ**, and sample/quote/visit CTAs open and prefill it. Visible wording distinguishes **Khách hàng cần trà** and **Đối tác giới thiệu**; backend role values remain `buyer|connector`. Customer company/name/contact remain the buyer identity for Pipeline matching. Referral-partner mode requires a separate responsible name and valid email/phone, stored only in private intake notes with customer authorization. Switching roles resets consent; omitted server roles preserve the legacy note for in-flight retries. Kg/date/channel/specification fields are optional. A request is not an order or appointment confirmation. Currency follows the display until the buyer explicitly selects a different quotation currency. Existing sample, quotation, order, procedure and reorder workflows remain downstream of the same Pipeline. Public Partner Network registration remains closed pending the owner's launch decision.
