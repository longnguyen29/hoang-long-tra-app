# Working with Hoàng Long business context

The staff guide at `/admin/work/guide` and the workflow map in `lib/company-guide.js` identify the source records for samples, wholesale quotes, batch quality, payments, and staff handoffs. When a request depends on a business fact, use the matching source if available. The map contains descriptions of the records. Current prices, stock, payments and customer agreements belong to the live system.

A staff member can attach selected approved decisions and reviewed topics using **Sao chép bản giao việc**. Each excerpt identifies its record, status category and review date where available. Treat it as a dated snapshot. Check the source before acting on time-sensitive facts. When the source is unavailable, identify the missing record.

For corrections intended to apply across the company, the existing review queue is **Hôm nay → Điều công ty cần nhớ**. A customer-specific exception belongs in that customer's profile.
