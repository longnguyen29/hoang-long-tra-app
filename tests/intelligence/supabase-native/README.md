# Disposable Supabase native authentication test

`bash tests/intelligence/supabase-native/run.sh` creates an isolated temporary Supabase project and `SUPABASE_HOME`, downloads the official pinned Supabase CLI and experimental native service artifacts, starts only local Auth/PostgREST/PostgreSQL services and verifies that observed TCP listeners in the stack process tree bind loopback and own the advertised API and database ports before testing. It never links a hosted project, uses a production database or customer data, sends messages or makes paid API calls. It destroys its own named stack and temporary data on exit; if cleanup fails, it reports and preserves the temporary directory for safe cleanup.

Requires Node/npm, Python 3, `psql`, `lsof`, internet access for the first download, and a supported Supabase native runtime (macOS Apple Silicon or Linux; see official docs). The CLI is pinned to 2.122.0 and native mode is experimental. A fresh cache can need significant disk space. Startup may take several minutes. Do not repoint this harness to an existing project, copy credentials into chat, or store its generated local tokens.

It uses the real local Supabase Auth service to create two fictitious users, signs them in for real JWTs, applies repository migrations 0057–0060 and the **unnumbered patched candidate** only to the disposable local database, and checks manager vs staff/anon access, invalid-signature JWT rejection, idempotency, hidden claim token, service-only worker RPC, and DNC evidence suppression through real PostgREST/RLS. It creates minimal fictional `staff_roles` and `tea_batches` business dependencies; their complete production schema, later migrations, actual deployed authorization, real customer data, Next.js routes and network worker are not tested. A pass does not authorize migration or release.

On 2026-10-29, this test passed on Supabase native PostgreSQL 17.11, GoTrue and PostgREST using fictional users; all stack listeners observed were loopback. The existing production database was not modified.
